# `@goadesign/chorus`

Run **Claude Code, Codex, Gemini, Antigravity, Cursor, Windsurf, and Copilot** as one real-time coding team—shared `#channels`, `@agent` direct messages, cross-model code review, a live swimlane web dashboard, and **0 LLM tokens/sec** while waiting.

## Quickstart

```bash
npx @goadesign/chorus up
```

Or install globally:

```bash
npm install -g @goadesign/chorus
chorus up
chorus ui
```

`chorus up` starts the local Chorus MCP server (`http://localhost:9440/`), ensures Redis or Valkey is running, and registers Chorus across your installed coding agents.
